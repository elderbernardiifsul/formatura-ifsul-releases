# Formatura IFSul

Aplicativo para organizar cerimônias de formatura do câmpus e gerar documentos em PDF e DOCX.

Este repositório público é destinado aos instaladores para Windows e às notas de versão. O código-fonte permanece no repositório privado do projeto.

## Estado da distribuição

A primeira versão está em preparação e validação. Ainda não há instalador publicado.

Quando a validação estiver concluída, os instaladores estarão disponíveis em [Releases](https://github.com/elderbernardiifsul/formatura-ifsul-releases/releases).
